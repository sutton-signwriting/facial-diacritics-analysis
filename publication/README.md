# Publication preparation

This folder contains preparation material for an optional Zenodo deposit, which
is currently deferred. Versioned data and website packages are published through
GitHub releases. No Zenodo record has been uploaded or published.

- [Zenodo field draft](zenodo-draft.json): title, creator, resource type, desired
  license, source snapshot, versions, keywords, relationships, and open fields.
- [Description HTML](zenodo-description.html): a reviewable description for the
  deposit form. Resolve and remove its local preparation note before publication.
- [Rights record](rights.json): licenses for the new contributions and the
  selected layered full release and recorded source notice, with its remaining
  scope question.
- [Source notice](source-licensing-notice.md) and
  [context audit](source-context-summary.json): evidence informing the release
  model without altering the current data.

The [publication plan](../docs/publication.md) owns release order, files, citation
relationships, rights decisions, and preparation checks. The
[journal comparison](../docs/data-publications.md) distinguishes a peer-reviewed
data/resource paper from the main *Language & Communication* manuscript.

The field draft follows the information pattern in the Sutton SignWriting
Platform record: a descriptive title, creator, explicit version, license scope,
archival identifier, living-site/repository links, and the role of related
objects. Its CC0 minimal-lexical-data proposal is not adopted as this project's
source license. The new facial resource is related work, not a ninth series
silently added to the frozen eight-series platform release.

DOI and publication date stay unset until an actual deposit and publication
exist. Funding and contributor information must be supplied accurately rather
than inferred. The public repository and inspection website URLs are verified;
the archival deposit remains in preparation.
